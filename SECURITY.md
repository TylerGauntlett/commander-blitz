# Security

If you find a vulnerability, please report it privately through
[GitHub's security advisories](https://github.com/TylerGauntlett/commander-blitz/security/advisories/new)
rather than in a public issue. You will get a reply within a week.

In scope: the server (`src/commanderblitz/server`), the deck importer, the desktop
shell and its updater, and the deploy pipeline under `.github/`. Out of scope:
rules bugs in the engine, which are ordinary issues.

The hosted game at [commanderblitz.com](https://commanderblitz.com) keeps no accounts
and stores nothing about you beyond the decks you import and the pod you are in.
